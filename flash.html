连接并烧录

请使用支持数据传输的 USB 线，推荐 Chrome 或 Edge 桌面版。

当前浏览器不支持 Web Serial，请改用 Chrome 或 Edge。 串口访问被浏览器阻止，请确认页面使用 HTTPS。

首次烧录建议在弹窗中选择“清除设备”。烧录完成后断开 USB，再按一下 RESET。

进入下载模式

  1. 普通连接：直接连接主板 USB-C，然后点击“连接设备”。
  2. 无法识别时：按住 BOOT（GPIO0），短按 RESET，松开 BOOT 后重新连接。
  3. 选择串口：Windows 通常显示为 USB JTAG/serial debug unit 或 COM 设备。
  4. 烧录期间：不要拔线、关闭页面或让电脑休眠。
安全提示

只烧录与屏幕型号匹配的官方固件。在线烧录会覆盖设备程序；TF 卡中的图片和音频不会被网页读取。
